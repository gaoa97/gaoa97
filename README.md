## How I Build

Every customer surface is built to one standard: say only what's true, keep it current without anyone watching, and never ask for more personal information than the job needs.

The method behind it is **Polycentric Intelligence**: specialised AI nodes with defined roles and handoffs. Claude for architecture, Gemini for research, ChatGPT for voice and operations, NotebookLM for document grounding.
